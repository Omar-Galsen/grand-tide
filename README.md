# Grand Tide

A browser-first isometric pirate action game prototype.

## Controls
- WASD / Arrow keys — Move
- J — Slash
- Space — Roll / dodge
- E — Interact
- P — Pause

## Current prototype
- Windward Island conquest objective
- 3 pirate scouts + Captain Redwake
- Player HP and gold
- Melee combat
- Dodge roll
- Boat-battle launch point
- Browser/mobile-friendly canvas setup

Open `index.html` in a browser to play.
